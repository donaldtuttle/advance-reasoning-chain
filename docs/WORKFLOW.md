# Workflow

1. Draft the answer without weakening or shortening it merely to make room for the follow-up.
2. Write the active goal as the first sentence of the answer in the exact form
   `Active goal: <one sentence>.`
   Then state the headline conclusion internally in one sentence.
   Immediately after the answer is complete, freeze the Minimal ARC Control Record before any candidate scoring.
3. Build an unranked candidate set operating only on the frozen record.
4–10. Score, select, and emit exactly one terminal line: `NEXT_PROMPT:` or `CHAIN_COMPLETE:`.

See `skills/advance-reasoning-chain/SKILL.md` for the full contract and quality test.
